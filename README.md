# COGNIVIA — كوغنيفيا

منصة تعليمية تفاعلية لدعم مهارات الانتباه والذاكرة واللغة والتفكير لدى الأطفال.

## الحالة الحالية
هذه النسخة هي نموذج أولي Frontend يعمل مباشرة في المتصفح. تحفظ التقدم محلياً على الجهاز باستخدام localStorage، ولا تتضمن بعد حسابات مستخدمين أو مزامنة سحابية أو تشخيصاً طبياً.

## التشغيل
افتح `index.html` في المتصفح، أو انشر المستودع كـ Static Site على Render.

## الوظائف الحالية
- لوحة رئيسية عربية RTL.
- أنشطة تفاعلية للذاكرة والانتباه واللغة والحساب.
- تحدٍّ يومي ونقاط وسلسلة إنجاز.
- سجل نتائج محلي ولوحة مبسطة لولي الأمر.
- تصميم داكن بأزرق عميق وفضي ولمسات سماوية.

## خارطة الطريق
1. اختبار الألعاب وتجربة الاستخدام على الهاتف والكمبيوتر.
2. إضافة تسجيل الدخول وقاعدة البيانات عبر Supabase.
3. حفظ جلسات التمرين وقياس الدقة وزمن الاستجابة.
4. تطوير الصعوبة التكيفية ولوحة التحليلات.
5. إضافة مساعد تعليمي بالذكاء الاصطناعي بعد إعداد مفاتيح الخدمة بأمان.

> كوغنيفيا منصة دعم وتدريب تعليمي، وليست أداة تشخيص طبي أو بديلاً عن تقييم المختصين.
