# وضع التركيز المستقل — وثيقة التصميم

## الهدف
إضافة تجربة تدريب مستقلة وهادئة للأطفال في COGNIVIA، مع تسجيل أداء الجلسات وعرض ملخصها في لوحة ولي الأمر، دون تغيير الأنشطة القائمة.

## النطاق
- صفحة مستقلة `/focus-test/` بأسلوب بصري هادئ ومتوافق مع العربية RTL والهاتف.
- أسئلة متعددة الخيارات قابلة للتقييم، سؤال واحد في كل مرة.
- تسجيل الإجابات والمحاولات وزمن الاستجابة والدقة وتفاصيل الجلسة.
- حفظ محلي بإصدار مخطط مستقل `cognivia-performance-v1`، دون تعديل أو ترحيل مفتاح `cognivia-progress` الحالي.
- إضافة مدخل واضح لوضع التركيز في الصفحة الرئيسية.
- عرض عدد الجلسات والأسئلة والدقة ومتوسط زمن الاستجابة وسجل الجلسات في لوحة ولي الأمر.

## السلوك والبيانات
- تبدأ ساعة السؤال باستخدام `performance.now()` عند عرضه، وتستخدم `Date.now()` فقط لطوابع ISO الزمنية.
- يسمح بمحاولتين كحد أقصى لكل سؤال؛ تسجل كل محاولة ونتيجتها وزمنها. بعد المحاولة الثانية أو الإجابة الصحيحة ينتقل الطفل للسؤال التالي.
- تقاس الدقة على أساس الإجابة الأولى حتى لا تخفي المحاولات اللاحقة الصعوبات الأولية.
- تحفظ الجلسة بمعرّف فريد، ويمنع تكرار حفظ الجلسة أو احتسابها مرتين.
- تحفظ بيانات مجهولة لا تتضمن اسم الطفل أو بريده.
- لا تمنح هذه المرحلة نقاطاً إضافية، ولا تغيّر رصيد الأنشطة القديم.
- البيانات محلية على الجهاز؛ لا تُدّعى مزامنة سحابية.

## القيود وما لن نبنيه
- الحفاظ على كل الأنشطة الحالية وآلية نقاطها كما هي.
- لا API routes أو backend جديد، لأن المشروع يستخدم Next.js static export.
- لا تشخيص لاضطراب الانتباه أو أي حالة طبية؛ المؤشرات تدريبية وصفية فقط.
- لا تغيير في إعدادات النشر أو نشر الإنتاج.

## النهج المعتمد
اختير وضع مستقل بدل تحويل الأنشطة الحالية إلى اختبارات موحدة؛ ذلك يعزل المخاطر ويحافظ على التجربة الحالية. التخزين المحلي ذو مخطط مستقل هو الأنسب حالياً لأن إعداد المزامنة السحابية غير مكتمل، ويمكن ترحيل البيانات لاحقاً دون تغيير شكل الجلسة.

## معايير القبول
1. الوصول إلى وضع التركيز من الصفحة الرئيسية عبر `/focus-test/`.
2. إكمال الأسئلة وتسجيل الإجابات الأولى والمحاولات وزمن الاستجابة.
3. لا تتكرر الجلسة أو نتائجها عند إعادة تحميل الصفحة.
4. لا يتغير `cognivia-progress` بسبب جلسات التركيز.
5. تعرض لوحة ولي الأمر إحصاءات صحيحة أو حالة فارغة واضحة.
6. يجتاز المشروع اختبارات وحدة الأداء و`npm run typecheck` و`npm run build`.
